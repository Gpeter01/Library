# Library
This is a demo library app you can use to store your books and alter your preferences. Here is a live preivew https://gpeter01.github.io/Library/.

## Key features
- Stores books
- Deletion of books
- Added functionality for change of book status

## *Insights*
I deviated slightly from the recommended and optimum path to follow to do this. The required outcome was acheived nonetheless. There is room for growth and improvement. 
The code used in this project is a little too *'clever'* if I dare say. The ideal next step here is to write simple, robust and more maintainable code.

## Concluion
This is an intermediate project to practice and further deepen one's understanding of DOM manipulation. It also fosters the use of constructors. An needed experience all in all.
